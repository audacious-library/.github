# Audacious - Play Music Files You Already Have

![Audacious playing a folder of music the user owns](https://audacious-media-player.org/images/audacious-4.0.2.png)

## Product Snapshot

Audacious is a music player with a queue, an equalizer, and a window that stays out of the way. It does not include a store. You add files you bought, recordings you made, or rips you were allowed to make from discs you own. Listening does not rewrite the tags unless you edit them on purpose.

Point it at one album folder first. A scan of an entire disk will index music that is not yours if other people keep files on this PC. Leave those folders out. The equalizer is a playback curve. It is not a new master of the song.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Play | A file you already have |
| Queue | The order of those files |
| Library | Folders you chose to add |
| Equalizer | A tone curve for playback |
| Output | The speakers or headphones you select |
| Tags | Left alone unless you edit them |

A skin changes the window. It does not add songs. If a file will not open, the copy is incomplete. Get it again from the place you acquired it legally.

## Deep Dive

Add the folder, play one track, and confirm the sound comes from the device you expect. Build a short queue you will actually finish. Do not add network indexes or sites that offer tracks you do not own. Close the player on a shared desk if the recent list shows private recordings.

Volume in the player and volume in Windows are both real. Check both before you reinstall. Audacious will not pull a streaming catalog offline, and a playlist file is not a license.

## Adoption Paths

Audacious fits a desk playlist of files you may play, and a check of an album you just copied from a disc you own. It fits one library folder. It does not fit a full-disk hunt, and it does not belong pointed at another user's music.

## Install Walkthrough

Prerequisites: A folder of audio you are allowed to play, and a working output device.

1. Install Audacious and open it.
2. Add one music folder. Skip the rest of the disks.
3. Play one track and confirm the output device.
4. Queue a short set from that folder.
5. Stop there. Do not add sources that offer songs you do not own.
